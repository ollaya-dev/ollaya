[d1-3B by Liquid AI](https://huggingface.co/LiquidAI/d1-3B) is a multimodal decision model based on LFM2.5-VL-3B. Ollaya reads its answer-token probabilities directly, with the author's prompt and max-pooled answer forms, and never generates an explanation.

## Models

| Tag | Weights | Images |
|---|---|---|
| `d1`, `d1:3b` | Author Q8_0 GGUF, 2.87 GB | No |
| `d1:3b-vision` | Same GGUF plus the author's 583 MB Q8_0 projector | Yes |

Use the vision tag for image questions. Both tags use temperature 1.0, without additional calibration, and support predicate, choice and score questions. Scores take 2–10 levels. The context holds 32,768 positions. Questions run independently because the model has recurrent state.

Typed-decisions accuracy, the argmax against the majority label on all 400 states and measured by Ollaya on an RTX 5090, is 0.650 (choice 0.603, score 0.571, yes/no 0.802), with a calibration error (ECE) of 0.033 at temperature 1.0.
