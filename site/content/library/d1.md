[d1-3B by Liquid AI](https://huggingface.co/LiquidAI/d1-3B) is a multimodal decision model based on LFM2.5-VL-3B. Ollaya reads its answer-token probabilities directly, with the author's prompt and max-pooled answer forms, and never generates an explanation.

> Needs Ollaya 0.13.0 or newer, the first release that runs the `d1-v1` layout. Update first (`ollaya --version`); an older version downloads the weights and then refuses to load them.

## Models

| Tag | Weights | Images |
|---|---|---|
| `d1`, `d1:3b` | Author Q8_0 GGUF, 2.87 GB | No |
| `d1:3b-vision` | Same GGUF plus the author's 583 MB Q8_0 projector | Yes |

Use the vision tag for image questions. Both tags use temperature 1.0, without additional calibration, and support predicate, choice and score questions. Scores take 2–10 levels. The context holds 32,768 positions. Questions run independently because the model has recurrent state.

Typed-decisions accuracy, the argmax against the majority label on all 400 states and measured by Ollaya on an RTX 5090, is {{result d1:3b typed.accuracy 3}} (choice {{result d1:3b typed.by_type.choice 3}}, score {{result d1:3b typed.by_type.score 3}}, yes/no {{result d1:3b typed.by_type.noul 3}}), with a calibration error (ECE) of {{result d1:3b typed.ece 3}} at temperature 1.0. Over HTTP on the RTX 5090 it answers five questions in {{result d1:3b gpu.p50_ms 0}} ms; each question evaluates the whole state again, so long states with many questions take longer.
