Decision 3.0 (d3) is the vLLM Semantic Router contributors' family of decision models, released under Apache-2.0 with their code in each model repository. Each is a fine-tuned Qwen3.5 whose full-attention layers read the whole prompt, with a readout over 255 answer codes at the last token. Every question is its own forward pass over the state, its instructions and its options. It never generates text.

The Decision Index numbers are the official text board's, from the model cards. The 26B models (`d3`, `d3-turbo`) use the same layout but need more memory than a 24 GB GPU in Ollaya's fp32 runtime, so they are not in the library.

## Usage

```shell
ollaya run d3 --preset triage "My order never arrived and support ignores me. Refund me today or I'm switching to your competitor."
```

Point any TypeSafe client at `http://localhost:11435` and set the model to `d3`.

## How it works

- **One sequence per question.** The state, the question and its options, each option behind a code (A, B, …); the readout picks a code at the last token. Questions do not see each other.
- **Temperature 1.** The probabilities are the softmax of the option logits, as upstream computes them.
- **Weights.** The files download from Hugging Face, pinned to a commit and verified by sha256, byte for byte the authors'. Ollaya hosts only the ONNX graph.
- **Tokenizer.** Upstream tokenizes with transformers 5's rebuild of the vocabulary, which differs from the repositories' `tokenizer.json` on some scripts (Devanagari, Thai). Ollaya uses the rebuild, the same file Bespoke Labs publishes with Nimble v2.
- **Parity.** Ollaya's Rust runtime matches upstream `d3_runtime` in fp32 for every tag: identical token sequences, the same rejections and the same decision on all 696 test questions, on CUDA and on the CPU.

## Limits

- **Context.** 8,192 tokens per question; a longer question is rejected, never truncated.
- **Score questions.** 2 to 10 levels, distinct and nonempty.
- **Not ported.** Images and videos (upstream accepts them).
